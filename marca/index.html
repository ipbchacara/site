Como usar

  1. Extraia o arquivo .zip antes de abrir os arquivos.
  2. Instale as fontes: na pasta fontes, selecione os arquivos .ttf, clique com o botão direito e escolha Instalar (no Mac, dois cliques em cada arquivo).
  3. Comece pelos modelos: papel timbrado para documentos, modelo de apresentação para slides.
